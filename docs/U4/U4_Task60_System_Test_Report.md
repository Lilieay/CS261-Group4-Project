# Task60: U4 — รายงาน System Test การเผยแพร่บน Docker

## ข้อมูลการทดสอบ

| รายการ | รายละเอียด |
|---|---|
| ผู้ทดสอบ | รอระบุ |
| PO | รอระบุ |
| รุ่นโค้ด | `7bc35a759028d7b21d85dfa7504ce0995169ddd7` |
| Services | `sqlserver`, `backend`, `frontend` จาก Docker Compose |
| URL | Frontend `http://127.0.0.1:5000`, Backend `http://127.0.0.1:8000` |

## ขั้นตอน System Test

1. เปิด Docker Desktop และเริ่ม SQL Server/Backend/Frontend ตามคู่มือ
2. ตรวจ `http://127.0.0.1:8000/` และ `http://127.0.0.1:8000/docs`
3. Login ด้วยบัญชีทดสอบ
4. เปิดหน้าเผยแพร่ เลือก CS261 และกรอกข้อมูลครบ
5. กดเผยแพร่ แล้วตรวจข้อความสำเร็จ/หน้ารายละเอียด
6. เปิดหน้ารายวิชาและหน้าแนวข้อสอบของฉัน ตรวจรายการเดียวกัน
7. Login ด้วยบัญชีผู้ใช้อื่นและเปิดอ่านรายการ
8. ทดสอบข้อมูลไม่ครบ, token หมดอายุ และ Backend หยุดทำงาน
