### เกณฑ์การตรวจรับ

- เปิดหน้าค้นหารายวิชาได้และเห็นช่องค้นหา ปุ่มค้นหา และรายการรายวิชาโดยไม่เกิด JavaScript error
- ค้นหาด้วยรหัสเต็มและรหัสบางส่วนแล้วแสดงเฉพาะรายการที่ตรงเงื่อนไข
- ค้นหาด้วยคำในชื่อวิชาได้โดยไม่ต้องใช้ตัวพิมพ์ตรงกัน
- คำค้นที่ไม่พบแสดงข้อความที่เข้าใจได้และไม่ทำให้หน้าเสีย
- คำค้นที่มีช่องว่างส่วนเกินทำงานเหมือนคำค้นที่ตัดช่องว่างแล้ว
- กดเปิดคลังจากการ์ดรายวิชาแล้วไปยังหน้ารายวิชาที่เลือก
- การกดค้นหาหลายครั้งไม่ทำให้ผลลัพธ์เดิมปะปนกับผลลัพธ์ใหม่
- กรณี Backend ไม่พร้อม หน้าเว็บต้องไม่ค้างหรือแสดงข้อมูลผิด หากขั้นตอนนั้นอยู่ในขอบเขตของรุ่นที่เชื่อม Backend แล้ว

## 2. Demo Script

ส่วนนี้เป็นขั้นตอนเตรียมสาธิต ไม่ใช่ผล Demo จริง

### ก่อนเริ่มสาธิต

1. ตรวจว่าใช้ branch และ commit เดียวกับที่กรอกในข้อมูล UAT
2. เปิด Frontend ที่ `http://127.0.0.1:5000`
3. เตรียมเปิด Developer Tools ไว้ตรวจ Console โดยไม่บันทึกข้อมูลลับ
4. เตรียมคำค้น `CS261`, `CS`, `software` และ `XXXX999`
5. ตรวจว่าหน้า `courses.html` และไฟล์ JavaScript โหลดครบ ไม่มี 404 หรือ JavaScript error

### ลำดับการสาธิตหลัก

| ลำดับ | การกระทำของผู้สาธิต | สิ่งที่ต้องเห็น |
|---|---|---|
| 1 | เปิด `http://127.0.0.1:5000/courses.html` | เห็นหัวข้อคลังวิชา ช่องค้นหา ปุ่มค้นหา และการ์ดรายวิชา |
| 2 | พิมพ์ `CS261` แล้วกดค้นหา | เห็นรายการ `CS261` และสถานะจำนวนผลลัพธ์ |
| 3 | เปลี่ยนคำค้นเป็น `CS` | เห็นรายวิชาที่มีรหัสขึ้นต้นด้วย `CS` |
| 4 | เปลี่ยนคำค้นเป็น `software` | เห็นรายวิชาที่ชื่อมีคำค้น |
| 5 | เปลี่ยนคำค้นเป็น `XXXX999` | เห็นข้อความไม่พบวิชาและปุ่มกลับไปดูรายการทั้งหมด |
| 6 | ค้นหา `CS261` แล้วกด `เปิดคลัง` | ไปยัง `choose-courses.html?course=CS261` |
| 7 | กลับมาค้นหาใหม่หลายครั้ง | ผลลัพธ์เปลี่ยนตามคำค้นล่าสุดและไม่ปนกับผลเดิม |

### ผลที่ต้องเห็นในการ Demo

- หน้า Search โหลดได้โดยไม่เกิดข้อผิดพลาด
- ผลค้นหาตรงกับรหัสหรือชื่อที่กรอก
- กรณีไม่พบข้อมูลมีข้อความแจ้งที่เข้าใจได้
- การเปิดคลังใช้รหัสรายวิชาที่เลือกถูกต้อง
- หลักฐาน Demo มาจากการรันจริงของรุ่นระบบที่ระบุ ไม่ใช่จากตัวอย่างในเอกสารนี้
