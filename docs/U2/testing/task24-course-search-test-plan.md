Task24 U2 แผนทดสอบการค้นหารายวิชา

--วัตถุประสงค์--

ตรวจสอบว่าผู้ใช้สามารถค้นหารายวิชาได้จากรหัสวิชาหรือชื่อวิชา และระบบแสดงผลลัพธ์หรือข้อความแจ้งเตือนได้ถูกต้องในทุกกรณี

--ขอบเขตการทดสอบ--

-ช่องค้นหารายวิชา
-การค้นหาด้วยรหัสวิชา
-การค้นหาด้วยชื่อวิชา
-การค้นหาบางส่วนของรหัสหรือชื่อ
-กรณีไม่พบข้อมูล
-กรณีไม่ได้กรอกคำค้น
-การแสดงผลลัพธ์หลังค้นหา

--เงื่อนไขก่อนทดสอบ--

1. ระบบ Frontend และ Backend เปิดใช้งานแล้ว
2. ฐานข้อมูลมีข้อมูลรายวิชาทดสอบอย่างน้อย `CS261`
3. ผู้ทดสอบสามารถเปิดหน้าค้นหารายวิชาได้

## Test Cases ##

| ID | กรณีทดสอบ | ข้อมูลทดสอบ / ขั้นตอน | ผลลัพธ์ที่คาดหวัง |
|---|---|---|---|
| TC-01 | เปิดหน้าค้นหารายวิชา | เปิดหน้าค้นหารายวิชา | แสดงช่องค้นหาและปุ่มค้นหาโดยไม่เกิดข้อผิดพลาด |
| TC-02 | ค้นหาด้วยรหัสวิชาแบบเต็ม | กรอก `CS261` แล้วกดค้นหา | แสดงรายวิชา `CS261` ที่ตรงกับคำค้น |
| TC-03 | ค้นหาด้วยชื่อวิชาแบบเต็ม | กรอกชื่อรายวิชาที่มีอยู่ แล้วกดค้นหา | แสดงรายวิชาที่มีชื่อตรงกับคำค้น |
| TC-04 | ค้นหาด้วยคำค้นบางส่วน | กรอก `CS` แล้วกดค้นหา | แสดงรายวิชาที่มี `CS` อยู่ในรหัสหรือชื่อ |
| TC-05 | ค้นหาด้วยตัวพิมพ์เล็ก | กรอก `cs261` แล้วกดค้นหา | ระบบค้นหาได้ หรือจัดการตัวพิมพ์เล็ก/ใหญ่ตามที่กำหนด โดยไม่เกิดข้อผิดพลาด |
| TC-06 | ค้นหาด้วยคำที่ไม่มีข้อมูล | กรอก `XXXX999` แล้วกดค้นหา | แสดงข้อความว่าไม่พบรายวิชาที่ตรงกับคำค้น |
| TC-07 | ไม่กรอกคำค้น | เว้นช่องว่างแล้วกดค้นหา | ระบบแจ้งให้กรอกคำค้น หรือแสดงรายการทั้งหมดตามข้อกำหนดของระบบ |
| TC-08 | กรอกช่องว่างก่อนและหลังคำค้น | กรอก `  CS261  ` แล้วกดค้นหา | ระบบตัดช่องว่างส่วนเกินและค้นหาได้ถูกต้อง |
| TC-09 | ใช้อักขระพิเศษ | กรอกข้อความ เช่น `@#$%` แล้วกดค้นหา | ระบบไม่ล่ม และแสดงว่าไม่พบข้อมูลหรือแจ้งข้อมูลไม่ถูกต้อง |
| TC-10 | กดค้นหาหลายครั้ง | ค้นหา `CS261` แล้วเปลี่ยนเป็น `CS262` | ผลลัพธ์ครั้งหลังแสดงข้อมูลของ `CS262` และไม่ปนกับผลลัพธ์เดิม |
| TC-11 | เปิดรายละเอียดจากผลการค้นหา | ค้นหา `CS261` แล้วกดรายการวิชา | เปิดหน้ารายละเอียดของวิชาที่เลือกได้ถูกต้อง |
| TC-12 | Backend ไม่พร้อมใช้งาน | ปิด Backend แล้วลองค้นหา | หน้าเว็บแสดงข้อความแจ้งเตือนที่เข้าใจได้ และไม่ค้างหรือแสดงข้อมูลผิด |

## เกณฑ์ผ่าน ##

-กรณี TC-01 ถึง TC-11 ต้องทำงานตามผลลัพธ์ที่คาดหวัง
-กรณีไม่พบข้อมูลต้องไม่ทำให้ระบบล่ม
-กรณี Backend ไม่พร้อมต้องมีข้อความแจ้งเตือนผู้ใช้
-ผลลัพธ์ต้องตรงกับคำค้นและไม่แสดงข้อมูลของรายวิชาอื่นโดยไม่เกี่ยวข้อง
