# Task62: U5 — ยืนยันกติกาหน้าแนวข้อสอบของฉัน

## 1. วัตถุประสงค์

กำหนดข้อตกลงสำหรับหน้าแนวข้อสอบของฉัน เพื่อให้ผู้ใช้สามารถดู เปิดอ่าน แก้ไข และลบแนวข้อสอบที่ตนเองเผยแพร่ได้อย่างถูกต้องและปลอดภัย

## 2. ขอบเขตการทำงาน

- แสดงรายการแนวข้อสอบที่ผู้ใช้ปัจจุบันเป็นเจ้าของเท่านั้น
- เปิดอ่านแนวข้อสอบที่เลือกได้ถูกต้องตามรายการ
- แก้ไขข้อมูลแนวข้อสอบของตนเอง
- ลบแนวข้อสอบของตนเองโดยต้องยืนยันก่อน
- ป้องกันผู้ที่ไม่ใช่เจ้าของแก้ไขหรือลบรายการ
- แจ้งผลการดำเนินการทั้งกรณีสำเร็จและไม่สำเร็จ

## 3. ข้อมูลที่แสดงในรายการ

หน้าแนวข้อสอบของฉันต้องแสดงข้อมูลที่จำเป็นสำหรับระบุและเลือกแนวข้อสอบ เช่น

- รายวิชาและรหัสวิชา
- ชื่อแนวข้อสอบ
- ปีการศึกษาและภาคเรียน
- ช่วงสอบ
- หัวข้อ
- รูปแบบข้อสอบ
- จำนวนข้อ
- ผู้สอน
- ข้อมูลเสริม (ถ้ามี)

เมื่อเลือกเปิดอ่าน ต้องแสดงข้อมูลของรายการที่เลือกตรงกับข้อมูลที่บันทึกไว้ ไม่ใช่รายการอื่น

## 4. ข้อมูลที่แก้ไขได้

เจ้าของรายการสามารถแก้ไขข้อมูลต่อไปนี้ได้

- รายวิชา
- ชื่อแนวข้อสอบ
- ปีการศึกษา
- ภาคเรียน
- ช่วงสอบ
- หัวข้อ
- รูปแบบข้อสอบ
- จำนวนข้อ
- ข้อมูลเสริม

การแก้ไขต้องปรับปรุงรายการเดิม โดยคงรหัสรายการและเจ้าของเดิมไว้ และไม่สร้างรายการซ้ำ

หากเปลี่ยนรายวิชา รายการต้องย้ายไปแสดงในรายวิชาใหม่ และไม่ปรากฏในรายวิชาเดิมอีก

## 5. กติกาการตรวจสอบข้อมูล

ข้อมูลที่ส่งเพื่อแก้ไขต้องผ่านการตรวจสอบทั้งฝั่งฟอร์มและ Backend

- ต้องระบุรายวิชา ชื่อ ปีการศึกษา ภาคเรียน ช่วงสอบ หัวข้อ และรูปแบบข้อสอบ
- ชื่อแนวข้อสอบและหัวข้อต้องไม่เป็นช่องว่างล้วน
- ชื่อแนวข้อสอบที่ว่างต้องแจ้งให้ผู้ใช้กรอกชื่อแนวข้อสอบ
- จำนวนข้อต้องไม่เป็นค่าติดลบ
- ต้องไม่อนุญาตให้เลือกรหัสวิชาที่ไม่มีอยู่ในระบบ เช่น CS999
- หากข้อมูลไม่ถูกต้อง ต้องแจ้งข้อผิดพลาดและไม่บันทึกข้อมูลใด ๆ
- ข้อมูลเดิมต้องไม่เปลี่ยนแปลงเมื่อการตรวจสอบไม่ผ่าน

## 6. กติกาการลบรายการ

- เจ้าของรายการต้องยืนยันก่อนลบ
- หากยืนยันลบสำเร็จ รายการต้องหายจากหน้าแนวข้อสอบของฉันและหน้ารายวิชาที่เกี่ยวข้อง
- รายการที่ถูกลบต้องไม่สามารถเปิดอ่านได้อีก
- หากยกเลิกการลบ รายการและข้อมูลทั้งหมดต้องคงเดิม
- การลบรายการหนึ่งต้องไม่กระทบแนวข้อสอบอื่นหรือข้อมูลรายวิชา

## 7. กติกาด้านสิทธิ์

- ผู้ใช้ต้องเข้าสู่ระบบก่อนจัดการแนวข้อสอบของตนเอง
- ผู้ใช้ดูรายการในหน้าแนวข้อสอบของฉันได้เฉพาะรายการที่ตนเองเป็นเจ้าของ
- ผู้ใช้ทั่วไปยังสามารถอ่านแนวข้อสอบที่เผยแพร่ผ่านหน้ารายวิชาได้ตามสิทธิ์ของระบบ
- เฉพาะเจ้าของรายการเท่านั้นที่มีสิทธิ์แก้ไขหรือลบรายการ
- Backend ต้องตรวจสอบสิทธิ์เจ้าของทุกครั้งที่มีคำขอแก้ไขหรือลบ ไม่พึ่งพาการซ่อนปุ่มบนหน้าเว็บเพียงอย่างเดียว
- ผู้ที่ไม่ใช่เจ้าของต้องไม่สามารถแก้ไขหรือลบรายการผ่าน URL หรือคำขอ Backend โดยตรงได้

## 8. กรณีไม่พบรายการหรือดำเนินการไม่สำเร็จ

- หากผู้ใช้ยังไม่มีแนวข้อสอบ ให้แจ้งว่ายังไม่ได้เผยแพร่แนวข้อสอบ และมีปุ่มไปยังฟอร์มเผยแพร่
- หากรายการถูกลบไปแล้ว ต้องแจ้งว่าไม่พบรายการหรือถูกลบแล้ว
- หากแก้ไขหรือลบไม่สำเร็จ ต้องแจ้งผลตามจริงและไม่แสดงข้อความว่าสำเร็จ
- เมื่อดำเนินการไม่สำเร็จ ข้อมูลเดิมและรายการอื่นต้องไม่เปลี่ยนแปลง
- การแก้ไขหรือลบรายการที่ถูกลบไปแล้วต้องไม่ทำให้รายการกลับมา หรือไปเปลี่ยนแปลงรายการอื่น

## 9. ผลหลังแก้ไขหรือลบ

หลังแก้ไขสำเร็จ หน้าแนวข้อสอบของฉัน หน้าอ่าน และผลกรองในหน้ารายวิชาต้องใช้ข้อมูลล่าสุด

หลังลบสำเร็จ รายการต้องไม่ปรากฏในหน้าที่เกี่ยวข้องอีก รวมถึงหลังโหลดหน้าใหม่
