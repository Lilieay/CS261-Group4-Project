# Task67: U5 — แผนทดสอบการจัดการแนวข้อสอบของฉัน

## 1. วัตถุประสงค์

เพื่อทดสอบการดูผลงานของตนเอง การเปิดอ่าน การแก้ไข และการลบแนวข้อสอบ รวมถึงการตรวจสอบสิทธิ์เจ้าของรายการ การตรวจสอบข้อมูลก่อนบันทึก และการจัดการเมื่อการดำเนินการล้มเหลวหรือรายการถูกลบไปแล้ว

## 2. ขอบเขตการทดสอบ

1. **UI Test:** ทดสอบหน้าแนวข้อสอบของฉัน หน้าอ่าน หน้าแก้ไข และการยืนยันลบ
2. **API Test:** ทดสอบการเรียกดู แก้ไข และลบแนวข้อสอบ รวมถึงการตรวจสอบสิทธิ์และข้อมูลที่ส่งเข้ามา
3. **DAO Test:** ทดสอบการค้นหาตามเจ้าของ การอัปเดตข้อมูล และการลบรายการในฐานข้อมูล
4. **UI-API Test:** ทดสอบการทำงานร่วมกันระหว่างหน้าจอกับ API
5. **API-DAO Test:** ทดสอบการส่งคำขอจาก API ไปยังฐานข้อมูลและตรวจสอบผลลัพธ์
6. **System Test:** ทดสอบตั้งแต่เปิดหน้าของฉัน เปิดอ่าน แก้ไข และลบแนวข้อสอบ
7. **UAT:** ให้ผู้ใช้ตรวจสอบว่าระบบช่วยจัดการผลงานของตนเองได้ตรงตาม User Story และ Definition of Done

## 3. ข้อมูลตั้งต้นและเงื่อนไขก่อนทดสอบ

- มีบัญชีนักศึกษาอย่างน้อย 2 บัญชีที่สามารถเข้าสู่ระบบได้
- มีแนวข้อสอบของนักศึกษาแต่ละคน และมีรายการใน CS261 หลายปีการศึกษา
- มีรายวิชา CS261 และ CS102 อยู่ในระบบ ส่วน CS999 ใช้สำหรับทดสอบรายวิชาที่ไม่มีอยู่
- มีรายการที่ใช้ทดสอบการแก้ไข การเปลี่ยนรายวิชา การลบ และการยกเลิกการลบ
- สามารถตรวจสอบข้อมูลในหน้าของฉัน หน้ารายวิชา หน้าอ่าน และฐานข้อมูลตามสิทธิ์ที่ได้รับ
- สามารถจำลองกรณีบันทึกการแก้ไขหรือลบล้มเหลวได้
- กำหนดข้อมูลเดิมที่ถูกต้องไว้ก่อนทดสอบกรณีแก้ไขข้อมูลไม่ถูกต้องและกรณีดำเนินการล้มเหลว

## 4. Test Cases Specification

### U5-TC01: หน้าแนวข้อสอบของฉันแสดงเฉพาะผลงานของตนเอง

**ประเภทการทดสอบ:** UI, API, DAO, UI-API, API-DAO, System Test, UAT

**ข้อมูลตั้งต้น:** นักศึกษาสองคนเข้าสู่ระบบแยกกัน และแต่ละคนมีแนวข้อสอบของตนเอง โดยผลงานของทั้งสองคนสามารถอ่านได้จากหน้ารายวิชา

**วิธีทดสอบ**
1. เข้าสู่ระบบด้วยบัญชีนักศึกษาคนแรกและเปิดหน้าแนวข้อสอบของฉัน
2. ตรวจสอบรายการที่แสดง
3. ออกจากระบบและเข้าสู่ระบบด้วยบัญชีนักศึกษาคนที่สอง
4. เปิดหน้าแนวข้อสอบของฉันและตรวจสอบรายการ
5. เปิดหน้ารายวิชาเพื่อตรวจสอบว่ายังอ่านผลงานของอีกคนได้

**ผลที่คาดหวัง**
- แต่ละคนเห็นเฉพาะผลงานของตนเองในหน้าแนวข้อสอบของฉัน
- ไม่เห็นผลงานของอีกคนในหน้านี้
- ยังสามารถอ่านผลงานของนักศึกษาคนอื่นผ่านหน้ารายวิชาได้

### U5-TC02: เปิดอ่านผลงานของตนได้ตรงรายการที่เลือก

**ประเภทการทดสอบ:** UI, API, DAO, UI-API, API-DAO, System Test, UAT

**ข้อมูลตั้งต้น:** นักศึกษาเข้าสู่ระบบแล้ว และมีแนวข้อสอบ CS261 หลายรายการในหน้าของฉัน รวมรายการปี 2567 และ 2568

**วิธีทดสอบ**
1. เปิดหน้าแนวข้อสอบของฉัน
2. เลือกแนวข้อสอบ CS261 ปี 2567
3. เปิดอ่านรายละเอียด
4. เปรียบเทียบข้อมูลกับรายการที่เลือกและรายการอื่นในระบบ

**ผลที่คาดหวัง**
- เปิดอ่านแนวข้อสอบปี 2567 ที่เลือกได้ถูกต้อง
- วิชา ปี ภาคเรียน ช่วงสอบ รูปแบบ จำนวนข้อตรงกับรายการ
- ไม่เปิดแนวข้อสอบปี 2568 หรือผลงานของคนอื่นแทน

### U5-TC03: ยังไม่เคยเผยแพร่แนวข้อสอบ

**ประเภทการทดสอบ:** UI, API, DAO, UI-API, API-DAO, System Test, UAT

**ข้อมูลตั้งต้น:** นักศึกษาเข้าสู่ระบบแล้ว แต่ยังไม่มีแนวข้อสอบที่ตนเองเผยแพร่

**วิธีทดสอบ**
1. เปิดหน้าแนวข้อสอบของฉัน
2. ตรวจสอบข้อความที่แสดงและปุ่มดำเนินการ
3. ตรวจสอบว่าไม่มีรายการของผู้อื่นแสดงเป็นผลงานของตนเอง

**ผลที่คาดหวัง**
- แจ้งว่ายังไม่ได้เผยแพร่แนวข้อสอบ
- มีปุ่มไปยังฟอร์มเผยแพร่แนวข้อสอบ
- ไม่แสดงผลงานของคนอื่นเป็นของตน
- ไม่สร้างรายการขึ้นเอง

### U5-TC04: แก้ไขแล้วทุกหน้าที่เกี่ยวข้องใช้ข้อมูลล่าสุด

**ประเภทการทดสอบ:** UI, API, DAO, UI-API, API-DAO, System Test, UAT

**ข้อมูลตั้งต้น:** นักศึกษาเข้าสู่ระบบและเป็นเจ้าของแนวข้อสอบ CS261 ที่เผยแพร่แล้ว

**วิธีทดสอบ**
1. เปิดหน้าแนวข้อสอบของฉันและเลือกแนวข้อสอบที่ต้องการแก้ไข
2. เปลี่ยนชื่อ ปีการศึกษา ภาคเรียน ช่วงสอบ หัวข้อ รูปแบบ จำนวนข้อ และข้อมูลเสริม
3. บันทึกข้อมูลที่ถูกต้อง
4. ตรวจสอบหน้าแนวข้อสอบของฉัน หน้าอ่าน และผลกรองในหน้ารายวิชา
5. โหลดหน้าใหม่และตรวจสอบข้อมูลอีกครั้ง

**ผลที่คาดหวัง**
- แจ้งแก้ไขสำเร็จ
- ทุกหน้าที่เกี่ยวข้องแสดงข้อมูลล่าสุด
- ยังคงเป็นรายการเดิมและเจ้าของเดิม
- ไม่สร้างรายการซ้ำจากการแก้ไข

### U5-TC05: เปลี่ยนรายวิชาแล้วแนวข้อสอบย้ายไปวิชาใหม่

**ประเภทการทดสอบ:** UI, API, DAO, UI-API, API-DAO, System Test, UAT

**ข้อมูลตั้งต้น:** นักศึกษาเข้าสู่ระบบและเป็นเจ้าของแนวข้อสอบที่อยู่ใน CS261 โดยมี CS102 อยู่ในระบบด้วย

**วิธีทดสอบ**
1. เปิดหน้าแก้ไขแนวข้อสอบใน CS261
2. เปลี่ยนรายวิชาเป็น CS102
3. บันทึกข้อมูล
4. ตรวจสอบรายการในหน้ารายวิชา CS261 และ CS102
5. ตรวจสอบหน้าอ่านและหน้าแนวข้อสอบของฉัน

**ผลที่คาดหวัง**
- รายการหายจากหน้า CS261 และปรากฏใน CS102
- หน้าอ่านระบุรายวิชา CS102
- หน้าแนวข้อสอบของฉันยังมีรายการเดิม
- ชื่อ รหัสรายการ และเจ้าของคงเดิม
- ไม่สร้างสำเนาหรือกระทบรายการอื่น

### U5-TC06: แก้ไขด้วยข้อมูลไม่ถูกต้องต้องไม่บันทึก

**ประเภทการทดสอบ:** UI, API, DAO, UI-API, API-DAO, System Test, UAT

**ข้อมูลตั้งต้น:** นักศึกษาเข้าสู่ระบบและเป็นเจ้าของแนวข้อสอบ โดยเตรียมข้อมูลเดิมที่ถูกต้องไว้ก่อนเริ่มแต่ละรอบ

**วิธีทดสอบ**
1. เปิดหน้าแก้ไขแนวข้อสอบ
2. ทดสอบเว้นวิชา ชื่อ ปีการศึกษา ภาคเรียน ช่วงสอบ หัวข้อ และรูปแบบข้อสอบทีละช่อง
3. เริ่มรอบใหม่เพื่อทดสอบชื่อและหัวข้อที่เป็นช่องว่างล้วน
4. เริ่มรอบใหม่เพื่อทดสอบจำนวนข้อเป็น -1
5. เริ่มรอบใหม่เพื่อเปลี่ยนรายวิชาเป็น CS999
6. ทดสอบทั้งผ่านฟอร์มและส่งข้อมูลตรงไปยัง Backend
7. เปิดอ่านรายการอีกครั้งหลังแต่ละรอบ

**ผลที่คาดหวัง**
- ระบบแจ้งข้อมูลที่ไม่ถูกต้องและไม่บันทึกการแก้ไข
- กรณีชื่อว่างแจ้งให้กรอกชื่อแนวข้อสอบ
- Backend ปฏิเสธข้อมูลที่ไม่ถูกต้อง แม้ข้ามการตรวจสอบบนหน้าเว็บ
- ไม่มีการบันทึกเฉพาะบางช่อง
- เมื่อเปิดรายการอีกครั้ง ข้อมูลทุกช่องยังเป็นข้อมูลเดิม

### U5-TC07: ยืนยันลบผลงานของตนเอง

**ประเภทการทดสอบ:** UI, API, DAO, UI-API, API-DAO, System Test, UAT

**ข้อมูลตั้งต้น:** นักศึกษาเข้าสู่ระบบและเป็นเจ้าของแนวข้อสอบ CS261 ที่ยังอยู่ในระบบ

**วิธีทดสอบ**
1. เปิดหน้าแนวข้อสอบของฉัน
2. เลือกรายการที่ต้องการลบ
3. กดลบและยืนยันการลบ
4. ตรวจสอบหน้าของฉันและหน้ารายวิชา
5. ลองเปิดลิงก์รายการเดิมและโหลดหน้าใหม่

**ผลที่คาดหวัง**
- แจ้งลบสำเร็จ
- รายการหายจากหน้าของฉันและหน้ารายวิชา
- ไม่สามารถเปิดอ่านรายการที่ถูกลบได้อีก
- รายการยังคงถูกลบหลังโหลดหน้าใหม่
- แนวข้อสอบอื่นและข้อมูลรายวิชาไม่ถูกลบตาม

### U5-TC08: ยกเลิกการลบแล้วผลงานยังอยู่

**ประเภทการทดสอบ:** UI, API, DAO, UI-API, API-DAO, System Test, UAT

**ข้อมูลตั้งต้น:** เจ้าของเข้าสู่ระบบแล้ว และมีแนวข้อสอบที่ยังอยู่ในระบบ

**วิธีทดสอบ**
1. เปิดหน้าแนวข้อสอบของฉัน
2. เลือกรายการและกดลบ
3. เลือกยกเลิกในขั้นตอนยืนยัน
4. ตรวจสอบรายการและเปิดอ่านอีกครั้ง

**ผลที่คาดหวัง**
- รายการยังปรากฏในหน้าของฉัน
- ยังสามารถเปิดอ่านได้
- ข้อมูลทั้งหมดคงเดิม
- ไม่แจ้งว่าลบสำเร็จ

### U5-TC09: นักศึกษาที่ไม่ใช่เจ้าของแก้ไขหรือลบไม่ได้

**ประเภทการทดสอบ:** UI, API, DAO, UI-API, API-DAO, System Test, UAT

**ข้อมูลตั้งต้น:** นักศึกษาเข้าสู่ระบบแล้ว แต่ไม่ใช่เจ้าของแนวข้อสอบที่กำลังทดสอบ

**วิธีทดสอบ**
1. เปิดอ่านแนวข้อสอบของนักศึกษาคนอื่น
2. ตรวจสอบว่าหน้าอ่านไม่มีปุ่มจัดการของเจ้าของ
3. ทดลองเปิดหน้าแก้ไขโดยตรง
4. ทดลองส่งคำขอแก้ไขไปยัง Backend
5. ทดลองส่งคำขอลบไปยัง Backend
6. ตรวจสอบข้อมูลและเจ้าของรายการหลังการทดสอบ

**ผลที่คาดหวัง**
- หน้าอ่านไม่มีปุ่มจัดการสำหรับเจ้าของ
- หน้าแก้ไขและ Backend ปฏิเสธการดำเนินการที่ไม่มีสิทธิ์
- ข้อมูลและเจ้าของเดิมไม่เปลี่ยนแปลง
- รายการไม่ถูกลบ

### U5-TC10: แก้ไขหรือลบรายการที่ถูกลบไปแล้ว

**ประเภทการทดสอบ:** UI, API, DAO, UI-API, API-DAO, System Test, UAT

**ข้อมูลตั้งต้น:** เจ้าของเปิดหน้าแนวข้อสอบของฉันค้างไว้ และรายการถูกลบสำเร็จจากอีก Session ของบัญชีเดียวกันแล้ว

**วิธีทดสอบ**
1. เปิดหน้าแนวข้อสอบของฉันไว้ใน Session แรก
2. ใช้อีก Session หนึ่งลบรายการให้สำเร็จ
3. กลับมายังหน้าเดิมและลองบันทึกการแก้ไขรายการนั้น
4. เริ่มทดสอบอีกครั้งโดยลองลบรายการเดิม
5. ตรวจสอบข้อความแจ้งผลและรายการอื่นในระบบ

**ผลที่คาดหวัง**
- แจ้งว่าไม่พบรายการหรือรายการถูกลบแล้ว
- ไม่สร้างรายการกลับมา
- ไม่แจ้งแก้ไขหรือลบสำเร็จ
- ไม่เปลี่ยนแปลงหรือลบรายการอื่นแทน

### U5-TC11: แก้ไขหรือลบล้มเหลวต้องไม่รายงานสำเร็จ

**ประเภทการทดสอบ:** UI, API, DAO, UI-API, API-DAO, System Test, UAT

**ข้อมูลตั้งต้น:** เจ้าของเข้าสู่ระบบแล้วและมีแนวข้อสอบที่ถูกต้อง โดยสามารถจำลองให้การบันทึกการแก้ไขหรือลบล้มเหลวได้

**วิธีทดสอบ**
1. เตรียมข้อมูลเดิมก่อนเริ่มแต่ละรอบ
2. จำลองให้การบันทึกการแก้ไขล้มเหลว แล้วทดลองเปลี่ยนชื่อและบันทึก
3. ตรวจสอบข้อความแจ้งผลและเปิดรายการอีกครั้ง
4. เริ่มรอบใหม่โดยจำลองให้การลบล้มเหลว แล้วกดยืนยันลบ
5. ตรวจสอบหน้าของฉัน หน้าอ่าน และรายการอื่นที่เกี่ยวข้อง

**ผลที่คาดหวัง**
- ระบบแจ้งว่าดำเนินการไม่สำเร็จ
- ไม่แจ้งแก้ไขหรือลบสำเร็จ
- รายการยังอยู่และข้อมูลยังเป็นค่าเดิมหลังเปิดใหม่
