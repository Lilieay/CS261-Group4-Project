# Task38: U3 — เตรียมแผนทดสอบรายการและหน้าอ่าน

## 1. วัตถุประสงค์

เพื่อทดสอบการแสดงรายการแนวข้อสอบ การกรองตามปีการศึกษา ภาคเรียน ช่วงสอบ และผู้สอน รวมถึงการเปิดอ่านรายละเอียดแนวข้อสอบให้ถูกต้อง โดยต้องแสดงข้อมูลตรงกับรายการที่เลือก ไม่ข้ามรายวิชา และจัดการกรณีข้อมูลไม่ครบหรือรายการไม่มีอยู่ได้อย่างเหมาะสม

## 2. ขอบเขตการทดสอบ

แบ่งการทดสอบออกเป็น 7 ประเภท ได้แก่

1. **UI Test:** ทดสอบการแสดงผลหน้าแนวข้อสอบ ตัวกรอง และหน้าอ่าน
2. **API Test:** ทดสอบการดึงรายการ การกรองข้อมูล และการเรียกรายละเอียดแนวข้อสอบ
3. **DAO Test:** ทดสอบการค้นหาและอ่านข้อมูลจากฐานข้อมูลให้ตรงกับเงื่อนไข
4. **UI-API Test:** ทดสอบการทำงานร่วมกันระหว่างหน้าจอกับ API
5. **API-DAO Test:** ทดสอบการส่งเงื่อนไขค้นหาและรับข้อมูลจากฐานข้อมูลผ่าน API
6. **System Test:** ทดสอบการทำงานตั้งแต่เลือกวิชา กรองรายการ จนถึงเปิดอ่าน
7. **UAT:** ให้ผู้ใช้ตรวจสอบว่าระบบตอบโจทย์การค้นหาและอ่านแนวข้อสอบตาม User Story

## 3. ข้อมูลตั้งต้นและเงื่อนไขก่อนทดสอบ

- ผู้ทดสอบเข้าสู่ระบบด้วยบัญชีนักศึกษามหาวิทยาลัยธรรมศาสตร์แล้ว
- มีรายวิชา CS261 และรายวิชาอื่นในระบบ
- CS261 มีแนวข้อสอบหลายรายการ โดยมีข้อมูลปีการศึกษา ภาคเรียน ช่วงสอบ และผู้สอนแตกต่างกัน
- มีรายการที่ไม่ระบุผู้สอน จำนวนข้อ หรือคำแนะนำ
- มีรายการที่ตรงกับเงื่อนไขหลายข้อ และมีชุดเงื่อนไขที่ไม่พบผลลัพธ์
- มีรายการสำหรับทดสอบการเปิดอ่านจากลิงก์โดยตรง รายการที่ถูกลบ และข้อความที่มีลักษณะคล้ายแท็ก HTML

## 4. Test Cases Specification

### U3-TC01: ดูแนวข้อสอบทั้งหมดของวิชาโดยไม่กรอง

**ประเภทการทดสอบ:** UI, API, DAO, UI-API, API-DAO, System Test, UAT

**ข้อมูลตั้งต้น:** CS261 มีแนวข้อสอบหลายรายการ รวมรายการที่ไม่ระบุผู้สอน และมีแนวข้อสอบของวิชาอื่นในระบบ

**วิธีทดสอบ**
1. เข้าสู่ระบบและเปิดหน้ารายวิชา CS261
2. ตั้งตัวกรองทุกตัวเป็น “ทั้งหมด”
3. ตรวจสอบรายการที่แสดงและข้อมูลที่ใช้แยกรายการ

**ผลที่คาดหวัง**
- แสดงแนวข้อสอบ CS261 ครบตามข้อมูลที่มี
- แสดงชื่อ ปีการศึกษา ภาคเรียน และช่วงสอบเพื่อแยกรายการ
- ไม่แสดงแนวข้อสอบของรายวิชาอื่น
- รายการที่ไม่ระบุผู้สอนยังแสดงได้ตามปกติ

### U3-TC02: กรองแนวข้อสอบทีละเงื่อนไข

**ประเภทการทดสอบ:** UI, API, DAO, UI-API, API-DAO, System Test, UAT

**ข้อมูลตั้งต้น:** CS261 มีแนวข้อสอบที่แตกต่างกันตามปีการศึกษา ภาคเรียน ช่วงสอบ และผู้สอน

**วิธีทดสอบ**
1. เปิดหน้า CS261 และล้างตัวกรองก่อนเริ่มแต่ละรอบ
2. เลือกปีการศึกษาเพียงเงื่อนไขเดียว แล้วตรวจสอบผล
3. ทำซ้ำโดยเลือกภาคเรียน ช่วงสอบ และผู้สอนทีละเงื่อนไข
4. เปรียบเทียบผลลัพธ์กับข้อมูลตั้งต้น

**ผลที่คาดหวัง**
- แสดงเฉพาะแนวข้อสอบ CS261 ที่ตรงกับเงื่อนไขที่เลือกในแต่ละรอบ
- ไม่แสดงรายการที่ไม่ตรงกับเงื่อนไข
- การล้างตัวกรองก่อนแต่ละรอบทำให้ผลทดสอบไม่ถูกรบกวนจากรอบก่อนหน้า

### U3-TC03: กรองหลายเงื่อนไขร่วมกันโดยไม่ข้ามวิชา

**ประเภทการทดสอบ:** UI, API, DAO, UI-API, API-DAO, System Test, UAT

**ข้อมูลตั้งต้น:** มีแนวข้อสอบ CS261 และวิชาอื่นที่มีข้อมูลการสอบคล้ายกัน รวมถึงรายการ CS261 ที่ตรงครบทุกเงื่อนไขและตรงเพียงบางเงื่อนไข

**วิธีทดสอบ**
1. เปิดหน้ารายวิชา CS261
2. เลือกปีการศึกษา 2568
3. เลือกภาคเรียน 1
4. เลือกช่วงสอบกลางภาค
5. เลือกผู้สอนกลุ่มเรียนที่หนึ่ง
6. ตรวจสอบรายการที่ได้

**ผลที่คาดหวัง**
- แสดงเฉพาะแนวข้อสอบ CS261 ที่ตรงครบทั้งสี่เงื่อนไข
- ไม่แสดงรายการที่ตรงเพียงบางเงื่อนไข
- ไม่แสดงแนวข้อสอบของวิชาอื่น แม้ข้อมูลการสอบเหมือนกัน

### U3-TC04: ไม่พบผลจากตัวกรองและล้างตัวกรองได้

**ประเภทการทดสอบ:** UI, API, DAO, UI-API, API-DAO, System Test, UAT

**ข้อมูลตั้งต้น:** CS261 มีแนวข้อสอบอยู่ แต่มีชุดเงื่อนไขที่ไม่มีรายการใดตรงกัน

**วิธีทดสอบ**
1. เปิดหน้ารายวิชา CS261
2. เลือกเงื่อนไขที่ไม่มีรายการตรงกัน
3. ตรวจสอบข้อความแจ้งผลและพื้นที่แสดงรายการ
4. ล้างตัวกรองทั้งหมด

**ผลที่คาดหวัง**
- ระบบแจ้งว่าไม่พบแนวข้อสอบที่ตรงกับเงื่อนไข
- แสดงรายการว่างโดยไม่เกิดข้อผิดพลาด
- ไม่แจ้งว่าวิชานี้ไม่มีแนวข้อสอบทั้งหมด
- เมื่อล้างตัวกรองแล้ว แสดงแนวข้อสอบ CS261 กลับมาตามปกติ

### U3-TC05: เจ้าของและนักศึกษาอื่นเปิดอ่านข้อมูลตรงรายการได้

**ประเภทการทดสอบ:** UI, API, DAO, UI-API, API-DAO, System Test, UAT

**ข้อมูลตั้งต้น:** มีแนวข้อสอบ CS261 ที่เผยแพร่แล้ว โดยมีข้อมูลชื่อวิชา ปีการศึกษา ภาคเรียน ช่วงสอบ หัวข้อ รูปแบบ จำนวนข้อ ผู้สอน และคำแนะนำ

**วิธีทดสอบ**
1. เข้าสู่ระบบด้วยบัญชีเจ้าของแนวข้อสอบและเปิดอ่านรายการ
2. เข้าสู่ระบบด้วยบัญชีนักศึกษาอีกคนและเปิดอ่านรายการเดียวกัน
3. เปรียบเทียบข้อมูลที่แสดงกับข้อมูลที่เผยแพร่
4. ตรวจสอบว่านักศึกษาอีกคนไม่สามารถแก้ไขหรือลบรายการผ่านสิทธิ์การอ่านได้

**ผลที่คาดหวัง**
- ทั้งสองบัญชีอ่านข้อมูลของรายการเดียวกันได้ถูกต้อง
- รายละเอียดตรงกับข้อมูลที่เผยแพร่
- การเปิดอ่านไม่ทำให้ผู้ใช้อื่นได้รับสิทธิ์แก้ไขหรือลบรายการ

### U3-TC06: เปิดอ่านรายการที่ไม่ระบุข้อมูลเสริมได้

**ประเภทการทดสอบ:** UI, API, DAO, UI-API, API-DAO, System Test, UAT

**ข้อมูลตั้งต้น:** มีแนวข้อสอบที่ไม่ระบุจำนวนข้อ ผู้สอน หรือคำแนะนำ แต่มีข้อมูลหลักครบถ้วน

**วิธีทดสอบ**
1. เปิดหน้ารายวิชา CS261
2. เลือกรายการที่ไม่มีข้อมูลเสริมดังกล่าว
3. เปิดอ่านรายละเอียดและตรวจสอบช่องข้อมูลที่ว่าง

**ผลที่คาดหวัง**
- แสดงข้อมูลหลักของแนวข้อสอบได้ครบ
- จำนวนข้อและผู้สอนที่ว่างแสดงว่า “ไม่ระบุ” หรือข้อความที่ระบบกำหนด
- ไม่แทนข้อมูลที่ว่างด้วย 0 หรือข้อมูลสมมติ
- คำแนะนำที่ว่างไม่ทำให้หน้าอ่านผิดพลาด

### U3-TC07: เปิดรายการที่ไม่มีอยู่หรือถูกลบไปแล้ว

**ประเภทการทดสอบ:** UI, API, DAO, UI-API, API-DAO, System Test, UAT

**ข้อมูลตั้งต้น:** มี URL ของแนวข้อสอบที่ไม่มีอยู่ และมีรายการที่ถูกลบหลังจากผู้ใช้โหลดหน้ารายการไว้แล้ว

**วิธีทดสอบ**
1. เข้าสู่ระบบและเปิดหน้ารายวิชา CS261
2. เตรียมลิงก์รายการที่ไม่มีอยู่หรือรายการที่ถูกลบแล้ว
3. เปิดลิงก์โดยตรง หรือกดรายการเก่าที่ยังค้างอยู่
4. ตรวจสอบข้อความแจ้งผลและทดลองกลับหน้ารายวิชา

**ผลที่คาดหวัง**
- ระบบแจ้งว่าไม่พบแนวข้อสอบหรือรายการถูกลบ
- ไม่แสดงเนื้อหาเก่าหรือรายละเอียดของรายการอื่นแทน
- ไม่เกิดข้อผิดพลาดร้ายแรงของหน้าเว็บ
- ผู้ใช้สามารถกลับไปยังหน้ารายวิชาได้

### U3-TC08: ข้อความของผู้เผยแพร่ไม่กลายเป็นคำสั่งหน้าเว็บ

**ประเภทการทดสอบ:** UI, API, DAO, UI-API, API-DAO, System Test, UAT

**ข้อมูลตั้งต้น:** มีแนวข้อสอบที่ผู้เผยแพร่กรอกข้อความทั่วไปและข้อความที่มีลักษณะคล้ายแท็ก HTML เช่น `<script>alert('test')</script>`

**วิธีทดสอบ**
1. เตรียมและเผยแพร่แนวข้อสอบที่มีข้อความทดสอบดังกล่าว
2. เข้าสู่ระบบด้วยบัญชีนักศึกษา
3. เปิดอ่านแนวข้อสอบ
4. ตรวจสอบการแสดงข้อความและพฤติกรรมของหน้าเว็บ

**ผลที่คาดหวัง**
- ข้อความที่ผู้เผยแพร่กรอกแสดงเป็นข้อความ ไม่ถูกประมวลผลเป็นคำสั่ง HTML หรือ JavaScript
- ไม่มีสคริปต์หรือพฤติกรรมที่ไม่พึงประสงค์ทำงาน
- ข้อมูลส่วนอื่นของแนวข้อสอบยังแสดงตามปกติ
