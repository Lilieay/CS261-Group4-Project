เอกสารนี้เป็นแบบบันทึก UAT และ Demo Script สำหรับการเลือกรายวิชา กรองรายการแนวข้อสอบ และเปิดอ่านรายละเอียดแนวข้อสอบ แยกผลการทดสอบจริงออกจากขั้นตอนสาธิตอย่างชัดเจน ตารางผลจริงต้องกรอกหลังทดสอบรุ่นระบบที่ระบุและมีหลักฐานแล้วเท่านั้น เอกสารนี้ยังไม่ใช่ผล Demo จริง

### ข้อมูลเตรียมทดสอบ

| ชุดข้อมูล | ค่า | วัตถุประสงค์ |
|---|---|---|
| รายวิชา | `CS261` | ใช้เป็นรายวิชาหลักในการทดสอบ |
| รายการที่มีข้อมูลครบ | แนวข้อสอบ CS261 ปีการศึกษา 2567/2568 | ตรวจรายละเอียดหลักและข้อมูลประกอบ |

| ข้อความทดสอบความปลอดภัย | `<script>alert('test')</script>` | ตรวจว่าเนื้อหาแสดงเป็นข้อความ ไม่ทำงานเป็นสคริปต์ |

ทดสอบผ่าน Frontend, Backend และ SQL Server จริงหลัง Login ใช้รายวิชา CS261 และรายการจาก API เท่านั้น เปิดหน้าอ่านจากลิงก์ในหน้าคลังซึ่งมี `source=api` และรหัสแนวข้อสอบจริง ห้ามใช้รายการตัวอย่างในเบราว์เซอร์เป็นผลตรวจรับ

### เกณฑ์การตรวจรับ

- เปิดรายการแนวข้อสอบของ `CS261` ได้และไม่แสดงรายการของวิชาอื่น
- กรองตามปีการศึกษา ภาคเรียน และช่วงสอบได้ถูกต้องทั้งทีละเงื่อนไขและหลายเงื่อนไข
- เมื่อไม่พบผลลัพธ์ ระบบแสดงข้อความที่เข้าใจได้และล้างตัวกรองกลับมาได้
- เปิดอ่านรายการที่เลือกแล้วรายละเอียดตรงกับรายการนั้น
- รายละเอียดแสดงชื่อวิชา ปีการศึกษา ภาคเรียน ช่วงสอบ หัวข้อ รูปแบบ จำนวนข้อ และคำแนะนำตามข้อมูลจริง
- ข้อมูลเสริมที่ไม่มีแสดงเป็น `ไม่ระบุ` หรือข้อความที่ระบบกำหนด โดยไม่แทนด้วยข้อมูลสมมติ
- รายการที่ไม่มีอยู่หรือถูกลบไม่แสดงรายละเอียดของรายการอื่นแทน และกลับหน้ารายวิชาได้
- ข้อความจากผู้เผยแพร่แสดงเป็นข้อความ ไม่ถูกประมวลผลเป็น HTML หรือ JavaScript
- ผู้ใช้ที่มีสิทธิ์อ่านสามารถเปิดรายการได้ แต่การอ่านไม่เพิ่มสิทธิ์แก้ไขหรือลบรายการ

## 2. Demo Script

ส่วนนี้เป็นขั้นตอนเตรียมสาธิต ไม่ใช่ผล Demo จริง

### ก่อนเริ่มสาธิต

1. ตรวจว่าใช้ branch และ commit เดียวกับที่กรอกในข้อมูล UAT
2. เปิด Frontend ที่ `http://127.0.0.1:5000`
3. เตรียมข้อมูลแนวข้อสอบของ `CS261` ที่มีทั้งรายการข้อมูลครบและรายการข้อมูลเสริมไม่ครบ
4. เตรียมคำสั่งหรือ URL สำหรับเปิดรายการที่ไม่มีอยู่ เพื่อสาธิตกรณีผิดพลาด
5. เปิด Developer Tools ไว้ตรวจ Console โดยไม่บันทึก password หรือ token

### ลำดับการสาธิตหลัก

| ลำดับ | การกระทำของผู้สาธิต | สิ่งที่ต้องเห็น |
|---|---|---|
| 1 | เปิดหน้าคลัง `CS261` | เห็นชื่อวิชา จำนวนรายการ ตัวกรอง และรายการแนวข้อสอบ |
| 2 | ตั้งตัวกรองทั้งหมดเป็น `ทั้งหมด` | เห็นรายการของ `CS261` และข้อมูลปี/ภาคเรียน/ช่วงสอบ |
| 3 | เลือกปีการศึกษา ภาคเรียน และช่วงสอบ | รายการเปลี่ยนเป็นเฉพาะผลที่ตรงกับตัวกรอง |
| 4 | เลือกเงื่อนไขที่ไม่พบผล แล้วกดล้างตัวกรอง | เห็นข้อความไม่พบ และรายการกลับมาเมื่อเคลียร์ตัวกรอง |
| 5 | กด `ดูเอกสาร` ของรายการที่เลือก | เปิดหน้าอ่านและเห็นรายละเอียดของรายการนั้น |
| 6 | ตรวจหัวข้อ รูปแบบ จำนวนข้อ และคำแนะนำ | ข้อมูลตรงกับรายการที่เผยแพร่ และค่าว่างแสดงตามที่กำหนด |
| 7 | เปิดรายการที่ไม่มีอยู่ | เห็นข้อความไม่พบแนวข้อสอบและปุ่มกลับหน้ารายวิชา |
| 8 | แสดงข้อความทดสอบที่มีลักษณะเป็น HTML | ข้อความแสดงเป็นตัวอักษร ไม่มี script หรือ alert ทำงาน |

### URL ตัวอย่างสำหรับ Demo

```text
http://127.0.0.1:5000/choose-courses.html?course=CS261
http://127.0.0.1:5000/read-courses.html?source=api&course=CS261&guide=<guide-id-จาก-API>
```

แทน `<guide-id-จาก-API>` ด้วย ID จริงจากรายการ CS261 หรือเปิดผ่านปุ่มดูเอกสารในหน้าคลัง ไม่ใช้ ID ตัวอย่างเป็นหลักฐาน

### ผลที่ต้องเห็นในการ Demo

- รายการที่แสดงอยู่ในรายวิชาที่เลือกและตรงกับตัวกรอง
- หน้าอ่านแสดงรายละเอียดของรายการที่เลือก ไม่ใช่รายการอื่น
- กรณีไม่มีข้อมูลหรือรายการถูกลบมีข้อความแจ้งที่เข้าใจได้
- เนื้อหาจากผู้ใช้ไม่ถูกประมวลผลเป็นคำสั่งหน้าเว็บ
- หลักฐาน Demo มาจากการรันจริงของรุ่นระบบที่ระบุ ไม่ใช่จากตัวอย่างในเอกสารนี้
