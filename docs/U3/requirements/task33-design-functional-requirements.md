# ข้อกำหนดของ U3: เลือกและเปิดอ่านแนวข้อสอบ CS

อ้างอิง: U3\_เลือกและเปิดอ่านแนวข้อสอบของรายวิชา CS.docx

## 1 การกรอง

ผู้ใช้ที่เข้าสู่ระบบเปิดรายวิชาจาก U2 แล้วเลือกกรองแนวข้อสอบได้ตามปีการศึกษา ภาคเรียน และช่วงสอบ ไม่มีตัวกรองตามผู้สอน

1. ตัวกรองทั้งสามเริ่มต้นที่ “ทั้งหมด” และแสดงทุกรายการของรายวิชานั้น
2. เมื่อเลือกหลายตัวกรอง ผลลัพธ์ต้องตรงกับทุกเงื่อนไข และไม่รวมรายการของวิชาอื่น
3. เปลี่ยนตัวกรองแล้วรายการอัปเดตทันที โดยไม่ต้องกดส่งฟอร์ม
4. ตัวเลือกมาจากแนวข้อสอบที่มีอยู่จริงในวิชานั้น หากยังไม่มีรายการ ให้มีเพียง “ทั้งหมด”
5. ปุ่มล้างตัวกรองคืนค่าทั้งสามเป็น “ทั้งหมด” และแสดงทุกรายการของวิชานั้น

## 2 ข้อมูลที่ต้องแสดง

### 2.1 รายการแนวข้อสอบก่อนเปิดอ่าน

| ข้อมูล | รายละเอียด |
| :---- | :---- |
| ชื่อแนวข้อสอบ | มาจากที่ผู้เผยแพร่กำหนด |
| ปีการศึกษา | ปีการศึกษาของแนวข้อสอบ เช่น 2567, 2568 |
| ภาคเรียน | ภาคเรียนที่ 1, 2, ซัมเมอร์ |
| ช่วงสอบ | เป็น กลางภาค / ปลายภาค |
| ชื่อผู้เผยแพร่ | ชื่อจากบัญชีของคนเผยแพร่ ที่ระบบจะนำมาใส่ให้เอง |

### 2.2 หน้าอ่านแนวข้อสอบ

เมื่อผู้ใช้ดูรายการแนวข้อสอบจากข้อที่แล้ว แล้วกดเปิดอ่าน สิ่งที่ผู้ใช้จะเห็นมีดังนี้

| ข้อมูล | รายละเอียด |
| :---- | :---- |
| ชื่อแนวข้อสอบ | มาจากที่ผู้เผยแพร่กำหนด |
| ปีการศึกษา | ปีการศึกษาของแนวข้อสอบ เช่น 2567, 2568 |
| ภาคเรียน | ภาคเรียนที่ 1, 2, ซัมเมอร์ |
| ช่วงสอบ | เป็น กลางภาค / ปลายภาค |
| ชื่อผู้เผยแพร่ | ชื่อจากบัญชีของคนเผยแพร่ ที่ระบบจะนำมาใส่ให้เอง |
| รายวิชา | เป็นชื่อ และรหัสรายวิชาของแนวข้อสอบนั้น |
| หัวข้อที่เคยออกสอบ | เป็นหัวข้อที่เคยออกสอบ ซึ่งมาจากที่ผู้เผยแพร่ได้กรอกมา |
| รูปแบบข้อสอบ |  ปรนัย , อัตนัย , ผสม |
| จำนวนข้อ | เป็นตัวเลขแสดงว่าปรนัยหรืออัตนัยกี่ข้อ ถ้าหากเป็นแบบผสม ต้องบอกจำนวนข้อของทั้งสองแบบ และหากไม่ระบุจำนวนข้อ ต้องแสดง “ไม่ระบุ” |
| คำแนะนำเพิ่มเติม | เป็นคำแนะนำเพิ่มเติมที่ผู้เผยแพร่ได้กรอกมา ถ้าหากไม่ได้กรอกมา ให้แสดง “ไม่ระบุ” |

## 3 ผลในกรณีต่าง ๆ

| กรณี | ผล |
| :---- | :---- |
| เปิดรายวิชาที่มีแนวข้อสอบในระบบ ยังไม่เลือกตัวกรอง | แสดงแนวข้อสอบทุกรายการ  |
| เลือกตัวกรองแล้วมีรายการที่ตรงเงื่อนไข | แสดงเฉพาะแนวข้อสอบที่ตรงเงื่อนไขของในวิชานั้น |
| เลือกตัวกรองแล้วไม่มีรายการที่ตรงเงื่อนไข | แสดงข้อความ “ไม่พบแนวข้อสอบที่ตรงกับที่กรอง” และไม่ขึ้นรายการแนวข้อสอบใด ๆ พร้อมมีปุ่มกดล้างตัวกรอง |
| รายวิชายังไม่มีแนวข้อสอบเลย | แสดงข้อความ “ยังไม่มีแนวข้อสอบสำหรับวิชานี้”  |
| เปิดรายการที่ไม่มีอยู่ หรือถูกลบไปแล้ว | แสดงข้อความ “ไม่พบแนวข้อสอบ” พร้อมให้กดกลับหน้ารายวิชา โดยไม่แสดงเนื้อหาเก่าหรือรายการอื่น |
| ยังไม่ได้เข้าสู่ระบบ หรือหมด session แล้ว | นำให้ผู้ใช้ไปที่หน้าเข้าสู่ระบบ |


หน้าจอปัจจุบันซ่อนผู้สอน เนื่องจากข้อมูลรายวิชายังไม่มีชื่อผู้สอน แม้ API ยังมีฟิลด์ `instructor_names` ส่วนรูปแบบคำขอและคำตอบดู [Task35](../design/task35-guide-api.md)
