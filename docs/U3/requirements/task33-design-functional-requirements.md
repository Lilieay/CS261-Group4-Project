# ข้อกำหนดของ U3: เลือกและเปิดอ่านแนวข้อสอบ CS

อ้างอิง: U3\_เลือกและเปิดอ่านแนวข้อสอบของรายวิชา CS.docx

## **1.การกรอง**

	หลังจากกดเข้ามาที่หน้าราชวิชาจาก U2 ในหน้ารายวิชานั้นจะขึ้นรายการแนวข้อสอบต่าง ๆ ที่มีมาให้เลือก และจะมีการกรองโดยมีกติกาดังนี้  
	1.1 ตัวกรองทุกตัวจะเริ่มต้นที่ “ทั้งหมด” เพื่อให้แสดงแนวข้อสอบทุกรายการในวิชา  
	1.2 เมื่อกดกรองข้อมูลแต่ละประเภท รายการที่แสดงต้องตรงกับในเงื่อนไขที่กรอง  
	1.3 เมื่อเลือกหลายตัวกรอง รายการที่แสดงต้องตรงกับทุกเงื่อนไข  
	1.4 ผลลัพธ์ที่กรองมา ต้องตรงกับในวิชานั้นเท่านั้น ไม่เอาของวิชาอื่นมาปะปน  
	1.5 ผู้ใช้สามารถกดเพื่อล้างตัวกรองได้ และเมื่อกด ตัวกรองทุกตัวต้องกลับมาเป็น “ทั้งหมด” และจะกลับมาแสดงทุกรายการ  
	1.6 ตอนกรองเมื่อเลือกเงื่อนไขที่ต้องการแล้ว รายการที่แสดงต้องอัปเดตทันที ไม่ต้องมากด submit เพื่อกรอง  
	1.7 ข้อมูลที่จะกรองทุกตัวกรอง จะเป็นข้อมูลจริงของแนวข้อสอบในระบบ เช่น ถ้ายังไม่มีแนวข้อสอบ ตัวกรองสมมติว่าเป็น drop down พอกดลงมาก็จะมีแค่ตัวเลือกทั้งหมด แต่ถ้าเกิดมีแนวข้อสอบในระบบแล้ว ตัวกรองก็จะอัปเดตมาให้กรอง พอกดลงมา อย่างเช่นกดกรองปีการศึกษา ก็จะขึ้น 2567, ทั้งหมด ให้เลือก 

## **2.ข้อมูลที่ต้องแสดง**

### 	2.1 รายการแนวข้อสอบก่อนเปิดอ่าน 	

| ข้อมูล | รายละเอียด |
| :---- | :---- |
| ชื่อแนวข้อสอบ | มาจากที่ผู้เผยแพร่กำหนด |
| ปีการศึกษา | ปีการศึกษาของแนวข้อสอบ เช่น 2567, 2568 |
| ภาคเรียน | ภาคเรียนที่ 1, 2, ซัมเมอร์ |
| ช่วงสอบ | เป็น กลางภาค / ปลายภาค |
| ชื่อผู้เผยแพร่ | ชื่อจากบัญชีของคนเผยแพร่ ที่ระบบจะนำมาใส่ให้เอง |

### 	2.2 หน้าอ่านแนวข้อสอบ

เมื่อผู้ใช้ดูรายการแนวข้อสอบจากข้อที่แล้ว แล้วกดเปิดอ่าน สิ่งที่ผูัใช้จะเห็นมีดังนี้

| ข้อมูล | รายละเอียด |
| :---- | :---- |
| ชื่อแนวข้อสอบ | มาจากที่ผู้เผยแพร่กำหนด |
| ปีการศึกษา | ปีการศึกษาของแนวข้อสอบ เช่น 2567, 2568 |
| ภาคเรียน | ภาคเรียนที่ 1, 2, ซัมเมอร์ |
| ช่วงสอบ | เป็น กลางภาค / ปลายภาค |
| ผู้สอน | ผู้สอนรายวิชานั้น ๆ ซึ่งระบบกำหนดไว้ที่รายวิชาอยู่แล้ว |
| ชื่อผู้เผยแพร่ | ชื่อจากบัญชีของคนเผยแพร่ ที่ระบบจะนำมาใส่ให้เอง |
| รายวิชา | เป็นชื่อ และรหัสรายวิชาของแนวข้อสอบนั้น |
| หัวข้อที่เคยออกสอบ | เป็นหัวข้อทึ่เคยออกสอบ ซึ่งมาจากที่ผู้เผยแพร่ได้กรอกมา |
| รูปแบบข้อสอบ |  ปรนัย , อัตนัย , ผสม |
| จำนวนข้อ | เป็นตัวเลขแสดงว่าปรนัยหรืออัตนัยกี่ข้อ ถ้าหากเป็นแบบผสม ต้องบอกจำนวนข้อของทั้งสองแบบ และหากไม่ระบุจำนวนข้อ ต้องแสดง “ไม่ระบุ” |
| คำแนะนำเพิ่มเติม | เป็นคำแนะนำเพิ่มเติมที่ผู้เผยแพร่ได้กรอกมา ถ้าหากไม่ได้กรอกมา ให้แสดง “ไม่ระบุ” |

## 3\. ผลที่ระบบจะแสดงออกมาในกรณีต่าง ๆ

| กรณี | ผล |
| :---- | :---- |
| เปิดรายวิชาที่มีแนวข้อสอบในระบบ ยังไม่เลือกตัวกรอง | แสดงแนวข้อสอบทุกรายการ  |
| เลือกตัวกรองแล้วมีรายการทีตรงเงื่อนไข | แสดงเฉพาะแนวข้อสอบที่ตรงเงื่อนไขของในวิชานั้น |
| เลือกตัวกรองแล้วไม่มีรายการที่ตรงเงื่อนไข | แสดงข้อความ “ไม่พบแนวข้อสอบที่ตรงกับที่กรอง” และไม่ขึ้นรายการแนวข้อสอบใด ๆ พร้อมมีปุ่มกดล้างตัวกรอง |
| รายวิชายังไม่มีแนวข้อสอบเลย | แสดงข้อความ “ยังไม่มีแนวข้อสอบสำหรับวิชานี้”  |
| เปิดรายการที่ไม่มีอยู่ หรือถูกลบไปแล้ว | แสดงข้อความ ‘ไม่พบแนวข้อสอบ“ พร้อมให้กดกลับหน้ารายวิชา โดยไม่แสดงเนื้อหาเก่าหรือรายการอื่น |
| ยังไม่ได้เข้าสู่ระบบ หรือหมด session แล้ว | นำให้ผู้ใช้ไปที่หน้าเข้าสู่ระบบ |
