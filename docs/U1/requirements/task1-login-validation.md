# Task1: U1 — ยืนยันกติกาและขอบเขตการเข้าสู่ระบบ


## 1. วัตถุประสงค์

กำหนดกติกาการเข้าสู่ระบบสำหรับนักศึกษามหาวิทยาลัยธรรมศาสตร์ที่ต้องการเข้าถึงและแบ่งปันข้อมูลเตรียมสอบรายวิชา CS โดยใช้บัญชีนักศึกษา TU ที่มีอยู่แล้ว โดยไม่ต้องสมัครบัญชีใหม่

## 2. ขอบเขตและสิทธิ์ผู้ใช้

1. ผู้ใช้ต้องเข้าสู่ระบบด้วยบัญชี TU ที่มีอยู่จริง
2. ระบบต้องตรวจสอบข้อมูลผ่าน TU API ก่อนอนุญาตให้เข้าใช้งาน
3. อนุญาตเฉพาะบัญชีที่ยืนยันได้ว่าเป็นนักศึกษา TU และมีสิทธิ์ใช้งาน
4. บัญชีอาจารย์และบุคลากรไม่มีสิทธิ์เข้าใช้งาน
5. หาก TU API ไม่พร้อมใช้งาน หรือไม่สามารถยืนยันสถานะนักศึกษาได้ ต้องไม่อนุญาตให้เข้าใช้งาน
6. การเข้าสู่ระบบด้วยบัญชี TU เดิมต้องเชื่อมกับผู้ใช้ภายในคนเดิม โดยไม่สร้างบัญชีซ้ำ

## 3. กติกาการตรวจสอบข้อมูล

1. บัญชีและรหัสผ่านต้องไม่เป็นค่าว่าง
2. บัญชีที่มีแต่ช่องว่างต้องถือว่าข้อมูลไม่ครบ
3. การตัดช่องว่างของบัญชีต้องไม่เปลี่ยนค่ารหัสผ่านที่ผู้ใช้กรอก
4. ข้อมูลที่ไม่ครบต้องไม่ถูกส่งไปยัง TU API
5. ระบบต้องตรวจสอบผลยืนยันตัวตนและประเภทบัญชีก่อนอนุญาตให้เข้าใช้งาน

## 4. ข้อกำหนดด้านความปลอดภัย

1. ห้ามจัดเก็บหรือแสดงรหัสผ่าน TU ในข้อมูลโปรไฟล์
2. ห้ามอนุญาตให้เข้าสู่ระบบหากยังไม่ได้รับการยืนยันจาก TU API
3. Backend ต้องตรวจสอบ Session และสิทธิ์ก่อนดำเนินการที่ต้องเข้าสู่ระบบ
4. ผู้ที่ไม่มี Session ที่ใช้งานได้ต้องไม่สามารถเข้าถึงข้อมูลที่ป้องกันไว้ผ่านหน้าเว็บหรือ Backend ได้
5. Session ที่หมดอายุหรือไม่ถูกต้องต้องถูกปฏิเสธ
6. การเข้าสู่ระบบด้วยบัญชี TU เดิมต้องไม่สร้างผู้ใช้ภายในซ้ำ
7. ข้อความแจ้งผลต้องไม่เปิดเผยรหัสผ่านหรือข้อมูลลับของผู้ใช้

## 5. ข้อความแจ้งผลการเข้าสู่ระบบ

| กรณี | ข้อความแจ้งผล |
|---|---|
| เข้าสู่ระบบสำเร็จ | เข้าสู่ระบบสำเร็จ |
| เข้าสู่ระบบไม่สำเร็จ | เข้าสู่ระบบไม่สำเร็จ กรุณาลองใหม่อีกครั้ง |

ข้อกำหนดเพิ่มเติม:
- ใช้ข้อความไม่สำเร็จเดียวกันเมื่อบัญชีหรือรหัสผ่านไม่ถูกต้อง บัญชีไม่มีสิทธิ์ TU API ขัดข้อง หรือไม่สามารถยืนยันสถานะนักศึกษาได้
- กรณีกรอกข้อมูลไม่ครบ สามารถแจ้งให้ผู้ใช้กรอกข้อมูลให้ครบได้ โดยไม่ต้องส่งคำขอไปยัง TU API
- การใช้ข้อความเดียวกันต้องไม่ทำให้ระบบอนุญาตบัญชีที่ไม่มีสิทธิ์เข้าใช้งาน
