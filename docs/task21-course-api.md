Task21: กำหนด API ค้นหาและเปิดดูรายวิชา

API สำหรับผู้ใช้งานทั่วไป

1. ดึงข้อมูลรายวิชาทั้งหมด

GET /courses ใช้สำหรับดึงข้อมูลรายวิชาทั้งหมดที่อยู่ในระบบ

2. ค้นหารายวิชา

GET /courses?search={รหัสหรือชื่อรายวิชา}

ใช้สำหรับค้นหารายวิชาจากรหัสหรือชื่อวิชา เช่น GET /courses?search=CS261


3. เปิดดูรายละเอียดรายวิชา

GET /courses/{course_id} ใช้สำหรับเปิดดูรายละเอียดของรายวิชาหนึ่งรายวิชา เช่น GET /courses/1


API สำหรับ Admin

 4. เพิ่มหรือนำเข้ารายวิชา 
 
 POST /admin/courses  ใช้สำหรับให้ Admin เพิ่มหรือนำเข้าข้อมูลรายวิชา กรณีมีรายวิชาใหม่หรือมีรายวิชาตกหล่น ผู้ใช้ทั่วไปไม่มีสิทธิ์เรียก API นี้

5. แก้ไขข้อมูลรายวิชา

PUT /admin/courses/{course_id} ใช้สำหรับให้ Admin แก้ไขข้อมูลรายวิชา ผู้ใช้ทั่วไปไม่มีสิทธิ์เรียก API นี้

6. ลบข้อมูลรายวิชา

DELETE /admin/courses/{course_id}  ใช้สำหรับให้ Admin ลบข้อมูลรายวิชา ผู้ใช้ทั่วไปไม่มีสิทธิ์เรียก API นี้

ตัวอย่างข้อมูลรายวิชา

{
  "id": 1,
  "course_code": "CS261",
  "course_name": "Software Engineering",
  "description": "วิชาวิศวกรรมซอฟต์แวร์"
}

การนำเข้าข้อมูลเริ่มต้น

ในช่วงเริ่มต้น ระบบจะนำเข้าข้อมูลรายวิชาพื้นฐานโดยทีมงานผ่าน Seed Data ก่อนเริ่มใช้งานระบบ หลังจากนั้น Admin จะเป็นผู้เพิ่ม แก้ไข หรือลบข้อมูลเมื่อมีรายวิชาใหม่ ข้อมูลตกหล่น หรือข้อมูลจำเป็นต้องแก้ไข
